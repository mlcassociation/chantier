# chantier

The readable open-source coding agent: a terminal harness that turns a model
into a coding agent — a loop, seven tools, and a deny-first permission ladder.
Interactive TUI, headless mode, pluggable providers (Anthropic and any
OpenAI-compatible endpoint).

```sh
npm install -g chantier
chantier --help
```

Requires Node >= 22. See the [monorepo README](https://github.com/mlcassociation/chantier)
for configuration, permissions, and headless examples.
